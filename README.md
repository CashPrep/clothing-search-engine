# Clothing Search Engine

An AI-powered product discovery platform that lets users search for clothing and products across retailers with photos, prices, details, direct links, and coupon support.

## Features
- Search products by vague or specific queries
- Product cards with image, title, price, retailer, and details
- Direct links to retailer product pages
- Verified coupon badges
- Modern responsive UI
- Mock retailer aggregation API for MVP

## Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- App Router

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
This MVP uses mocked retailer/product data and coupon verification placeholders. In production, you should integrate retailer APIs, affiliate networks, shopping feeds, and coupon providers while complying with each retailer's terms of service.
